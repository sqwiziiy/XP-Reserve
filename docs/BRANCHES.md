# Branches and releases

- `main` — primary development branch with current Minecraft 1.21.11 Fabric sources, Gradle build, and documentation.
- `wiki` — GitHub Pages documentation.
- `backup/main-before-restructure-2026-11-18` — temporary backup of the old documentation-only main (not a development branch).

## Releases and supported versions

The published release `v0.1.0-mc1.21.11` is preserved as a Git tag and GitHub Release. Use tags/releases for release snapshots rather than creating a permanent branch for each mod patch version.

Minecraft 1.21.1 and 1.20.1 ports are not yet available. Create separate maintenance branches if/when ports exist and need independent updates.
