# Mentalitys | XP Reserve

XP Reserve is a Fabric mod currently under development for Minecraft 1.21.11, using Java 21.

Its planned focus is reusable experience flasks that support survival-oriented XP risk management and recovery. No gameplay features are implemented yet.

Future ports to Minecraft 1.21.1 and 1.20.1 are planned only after the Fabric 1.21.11 version is complete.
