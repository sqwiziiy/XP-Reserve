# Mentalitys | XP Reserve

> [Русская версия](README_RU.md)

Reusable Fabric XP flasks that store exact experience, release it through vanilla Mending, and offer Soul Flask death insurance.

## Current release

**0.1.0**

- Supported Minecraft version: **1.21.11**
- Loader: **Fabric**
- Java: **21**
