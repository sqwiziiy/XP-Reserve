# Mentalitys | XP Reserve

> [English version](README.md)

Переносные многоразовые фляги опыта для Fabric. XP Reserve хранит опыт как точные очки XP и помогает безопасно распоряжаться им в выживании, при Починке и после смерти.

## Текущий релиз

**0.1.0** — кандидат в релизы

- Minecraft **1.21.11**
- **Fabric**
- **Java 21**

## Возможности

- Многоразовое хранение точных очков XP с частичным заполнением.
- Три ступени развития: запас до 30, 50 и 100 уровней.
- Высвобождение с учётом Починки: сначала опыт получает подходящее повреждённое снаряжение.
- Понятные подсказки с точным XP, пять состояний заполнения и блеск только у полной фляги.
- Страховка от смерти с Флягой души: после сохранения опыта она становится Флягой опыта III.
- Русская и английская локализация, ванильные рецепты, открытие рецептов и достижения.

## Фляги

| Предмет | Вместимость | Эквивалент уровня | Назначение |
|---|---:|---:|---|
| Фляга опыта I | 1 395 XP | 30 | Первый многоразовый запас |
| Фляга опыта II | 5 345 XP | 50 | Улучшенный запас |
| Фляга опыта III | 30 970 XP | 100 | Запас для долгих вылазок |
| Фляга души | 30 970 XP | 100 | Страховка от смерти; после срабатывания становится Флягой опыта III |

«Эквивалент уровня» — это опыт, нужный для достижения уровня с нуля. XP Reserve хранит точные очки XP, а не абстрактные уровни.

## Управление

| Управление | Действие |
|---|---|
| Shift + ПКМ | Сохранить столько опыта, сколько поместится |
| ПКМ | Высвободить весь сохранённый опыт |

При высвобождении сначала применяется ванильная Починка. Оставшийся опыт попадает в шкалу опыта игрока.

## Фляга души

Создайте Флягу души из Фляги опыта III и Тотема бессмертия. Её можно заполнять и высвобождать как обычную Флягу опыта III.

При настоящей смерти сначала проверяется Тотем бессмертия. Если смерть всё же происходит, одна подходящая Фляга души сохраняет столько опыта, сколько поместится, превращается во Флягу опыта III и выпадает вместе с обычными предметами игрока. Её нужно подобрать: лава, пустота или исчезновение предмета всё ещё могут её уничтожить. При `keepInventory` страховка не расходуется.

## Рецепты

### Фляга опыта I

```text
A L A
L B L
A L A

A = Осколок аметиста
L = Лазурит
B = Стеклянная бутылочка
```

### Улучшения

```text
Фляга опыта I   + Алмазный блок     -> Фляга опыта II
Фляга опыта II  + Компас восстановления -> Фляга опыта III
Фляга опыта III + Тотем бессмертия  -> Фляга души
```

Сохранённый XP остаётся во фляге при улучшении корректного предмета.

## Требования

- Minecraft **1.21.11**
- Fabric Loader **0.19.3** или совместимая версия
- Fabric API **0.141.6+1.21.11**
- Java **21**

## Установка

1. Установите Fabric Loader для Minecraft 1.21.11.
2. Установите подходящий Fabric API.
3. Поместите JAR XP Reserve в папку Minecraft `mods`.
4. Запустите Minecraft с Java 21.
