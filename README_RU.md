# Mentalitys | XP Reserve

> [English version](README.md)

Многоразовые Fabric-фляги опыта, которые хранят точный XP, высвобождают его с ванильной Починкой и дают страховку от смерти через Флягу души.

## Текущий релиз

**0.1.0**

- Поддерживаемая версия Minecraft: **1.21.11**
- Загрузчик: **Fabric**
- Java: **21**
